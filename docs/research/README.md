# Historical Research

This directory preserves completed maintenance plans, source-lineage evidence,
and inherited support artifacts that remain useful for historical or
compatibility review but are not authoritative runtime, packaging, or
installation inputs.

Files under `legacy-apps/` and `legacy-packaging/` must not be installed or
executed from this location. Current supported paths are documented in
`docs/development/legacy-support-files.md`.

Archiving a file here preserves Git history and attribution. It does not claim
that the file is secure, supported, or compatible with current systems.
